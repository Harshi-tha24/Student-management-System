# Student Management System

A web-based Student Management System developed using Flask and SQLite for managing student records.

## Features

* Add Student Records
* View Student Records
* Edit Student Details
* Delete Student Records
* SQLite Database Integration
* User-Friendly Interface

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS
* Git & GitHub

## Project Structure

│   ├── index.html

│   └── edit.html

├── static/

│   └── style.css

└── README.md

## How to Run

1. Install Flask

pip install flask

2. Run the application

py app.py

3. Open your browser

http://127.0.0.1:5000
